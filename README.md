# Mohammed Rachidi, services de jardinage

Site vitrine (Next.js 16, Tailwind CSS 4).

## Modifier le contenu

Tout le contenu est dans `src/content/site.ts` : numéro WhatsApp, ICE, villes, missions (photos, lieu, client), services et questions.
Les valeurs marquées `A CONFIRMER` sont à remplacer par les vraies informations.

## Développement

```bash
npm install
npm run dev
```

## Déploiement

Image Docker (`Dockerfile`, sortie `standalone`), port 3000.
